# eStream Assistant v0.1.10 (test build)

Owner feedback on v0.1.9.

## Fixed
- **Copy from the chat.** Chat messages can now be selected and copied (drag to highlight, then Ctrl+C or
  right-click → Copy). Scrolling the chat and barcode scans work as before.

## New
- **Copy chat button** (next to New chat): copies the whole chat with times, who said what, attachments and choices,
  ready to paste into a problem report.
- **Shorter replies from Claude.** Claude only says the answer or the one thing to do, e.g.
  "Scan the POPCORN 220 g barcode." No greetings, recaps or "let me know if…" endings. Now → New and the SAVE
  reminder are still given.

## Install
Download **eStreamAssistant-Setup-0.1.10.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
