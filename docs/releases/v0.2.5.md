# eStream Assistant v0.2.5 (test build)

Till receipts (Costco, Superstore) no longer ask for a quantity on every line.

## Fixed
- **A line with no count is one item.** Till receipts print one line per scan and only print a count when several
  were rung up at once ("10 @ 2.59" above the item). Lines without a count were asking for a quantity; now they
  count as 1. An item scanned again is its own line of 1, and they add up on the stock sheet (4 scans = 4).
- **Counts printed above the item are used.** "10 @ 2.59" gives that item 10. If it's missed, the app works it out
  from the line total (25.90 ÷ 2.59 = 10).
- Rows where the count wasn't printed show "qty 1 (not printed)", so you can see what was assumed. A printed count
  always wins, and a line with no count and no price is still asked about.
- Costco's instant-savings lines ("0000397895 / 242470  2.00-") aren't read as items.

## Install
Download **eStreamAssistant-Setup-0.2.5.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings, the saved API key, and
receipts saved for later.
