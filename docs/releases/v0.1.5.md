# eStream Assistant v0.1.5 (test build)

## Fixed
- **Claude chat failed on every message in v0.1.4** ("Claude couldn't read that request. Start a new chat").
  The new stock sheet tool pushed the tool schemas to the API's limit for nullable parameters, so every request was
  rejected. The two new report tools are now simpler (stock_sheets takes 0 to list the sheets) and the strict-schema
  setup is back to what v0.1.3 sent. A test now keeps the tools under the API limits.
- If Claude rejects a request again, the message now includes the reason from the API.

Everything else is as in v0.1.4 (Reports tab, stock reports, stock sheets). See `docs/releases/v0.1.4.md`.

## Install
Download **eStreamAssistant-Setup-0.1.5.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
