# eStream Assistant v0.2.3 (test build)

Fixes chat in v0.2.2: every message to Claude failed.

## Fixed
- **Claude answers again.** In v0.2.2 every message failed with *"Claude couldn't handle that message"*, so
  receipts couldn't be read and stock sheets couldn't be built from them. The receipt tool's definition had grown too
  large for Claude's API. Receipts, the Pending tab, and receipt names work the same as in v0.2.2.
- **A clearer message if this ever happens again.** Instead of "Start a new chat" (which couldn't help), the app
  says this version has a problem talking to Claude and to send in the Bugs list.

## Install
Download **eStreamAssistant-Setup-0.2.3.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings, the saved API key, and
receipts saved for later.
