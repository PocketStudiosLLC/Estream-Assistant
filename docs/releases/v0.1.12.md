# eStream Assistant v0.1.12 (test build)

Owner feedback from the Bugs list (2026-11-25).

## Fixed
- **12-digit barcodes on stock sheets:** eStream's import leaves them off (sheet 10768 lost both G.H.CRETORS items).
  A wrong sheet now says which items are missing by name: *"Sheet 10768 is wrong. DON'T post it. Missing:
  G.H.CRETORS CHICAGO MIX, G.H.CRETORS CHEESE CORN."* The script fix for the store PC is in
  `docs/store-pc-fix-12-digit.txt`.

## Changed
- **Shorter text:** receipt line warnings, the receipt stock sheet notes and the 12-digit warning say only what to do.
  After reading a receipt, Claude replies "N of M lines ready." and one line per thing to do, e.g.
  *"Line 4: scan the POPCORN 220 g barcode."*

## Install
Download **eStreamAssistant-Setup-0.1.12.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
