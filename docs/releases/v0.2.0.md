# eStream Assistant v0.2.0 (test build)

Long receipts can be read, and finished receipts stop costing tokens.

## New
- **Long receipts are read at full size.** A till roll scanned as one tall page (the Superstore receipt is
  1275 × 13974 px) used to come out "too blurry": Claude shrinks every page to about 2,600 px on its long side, which
  left it ~230 px wide. The app now cuts long receipts into strips by itself: it trims the blank margins and cuts in
  the blank space between printed lines, so no line is cut in half. Claude is told the strips are one receipt, in
  order, and that an item running across a cut is one item. The Superstore receipt goes as 6 strips.
- **Scanned PDFs are sent as pictures.** A PDF that is just scans (no typed text) has its scans taken out and sent
  as pictures (cut into strips when long). PDFs with typed text, like emailed invoices, still go as PDFs.
  The tray shows e.g. "PDF · 1.6 MB · read as 6 pictures".
- **Finished receipts leave the chat.** A receipt's pictures go with every message in the chat (about 16,000 tokens
  for a long receipt). Once every line of the receipt is on a POSTED stock sheet, the pictures are taken out of the
  chat with the next message and a line in the chat says so. While a line still needs you (an item to pick, a line
  Claude couldn't read), they stay. Finish receipt also takes them out. The receipt table stays either way; to show
  Claude the receipt again, attach it again.

## Install
Download **eStreamAssistant-Setup-0.2.0.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
