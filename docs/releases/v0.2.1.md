# eStream Assistant v0.2.1 (test build)

Plain-English messages when Claude can't answer.

## Fixed
- **Error messages no longer show the API's raw reply.** When Claude turned a message down, the chat showed the
  API's technical text (status code, JSON, request id). Now it says what happened and what to do, for example:
  *"The Claude account has run out of credit, so Claude can't answer right now. Whoever pays for the Claude account
  needs to add credit at console.anthropic.com (under Plans & Billing)."*
  There are also plain messages for an account on hold, a chat that has got too long, and an attached file Claude
  can't open. The technical details still go to the app log and the Bugs list.

## Install
Download **eStreamAssistant-Setup-0.2.1.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
