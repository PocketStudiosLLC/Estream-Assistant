# eStream Assistant v0.1.8 (test build)

Fixes from test 3 on the store PC (v0.1.7, 2026-11-23).

## Fixed
- **GM% is right for real items again.** The store sets up most single items as "1 pack × N units" (3,496 active
  items, e.g. COCA-COLA 1 × 32 at $2.25) and sells them one at a time. v0.1.7 worked out GM from the whole pack, like
  eStream's own GM% column, which gives 0% or less for those items. The app now uses the cost of one item as sold
  (case cost ÷ packs × units) for GM%, markup/margin prices and the margin report. When eStream's GM% column
  disagrees, the item card says so.
- **Margin reports work.** They failed with "Arithmetic overflow" on real data (very large or negative GM% values).
- **A SAVE has more time.** While eStream Server was busy, one item took up to 83 s and the save was stopped halfway.
  The limit is now 2 minutes + 90 s per item (old settings move up by themselves). If a save is still stopped,
  the items that finished show as saved, and the message says to close the item editor left open in eStream.
- **A stock sheet the script made wrong can't be posted.** On the Costco receipt, the script made sheet 10763 with
  9 of 10 lines and said so, but the app showed it as fine with a live Post button. Now the sheet is marked "NOT RIGHT:
  don't post, delete it in eStream", and the receipt lines can go on a new sheet. Sheet 10763 is marked too.
- **Claude knows what's in the lists now.** Every message tells Claude what the pending list, the count list and the
  receipt table hold, so it no longer says rows are "already in Pending changes" after the list was cleared, and it
  no longer promises a price batch for 2 items.

## New
- **Receipt codes match shelf codes.** A receipt's item number is tried as a UPC and as the item's Shelf Code (Costco
  item numbers are the store's shelf codes). A code that fits two items (Costco 1019 HALF & HALF vs. PLU 1019
  PROPANE) asks the owner to pick.
- **Old receipts warning.** When an item on a receipt has a negative on hand, the stock sheet window says how much
  posting really adds (e.g. -36 → 10 adds 46), so lines for goods already sold can be left out.
- Settings → Test connection names the models; the app log shows chat/receipt and the effort for every request;
  a failed report no longer leaves the previous report on screen; no more cache warning after a long pause.

## Install
Download **eStreamAssistant-Setup-0.1.8.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
Then follow `docs/test4.txt` on the store PC.
