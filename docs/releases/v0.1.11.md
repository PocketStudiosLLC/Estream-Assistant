# eStream Assistant v0.1.11 (test build)

Owner feedback on v0.1.10.

## Changed
- **Tab order:** Assistant · Stock counts · Reports · History · Settings (History moved between Reports and Settings).
- **"Dry run" is now "Run"** under Pending changes. When the list is empty, the box explains the difference: Run checks
  every change in eStream and throws it away (nothing is saved); SAVE does the same check by itself, shows the list,
  and only after you confirm puts the changes in eStream.

## New
- **Bugs button** (right of "?" at the top right): lists the errors and problems the app ran into while doing a task,
  newest first, with details. Shows "Bugs (3)" when there are new ones. They're saved in
  `%LOCALAPPDATA%\eStreamAssistant\issues.txt`; **Open file location** opens that folder with the file selected.
- **Colors button** on the Reports tab: stock counts get a red background below 0, yellow under 4 and green at 4 and up.

## Install
Download **eStreamAssistant-Setup-0.1.11.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
