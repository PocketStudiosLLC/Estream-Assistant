First test build for the store PC. **Lookups only: this version can't change anything in eStream.**

## Install

1. Download **eStreamAssistant-Setup-0.1.0.exe** below and run it. Admin rights aren't needed. It installs to `C:\eStreamAssistantApp\` and adds a Start menu shortcut.
2. The installer isn't code-signed yet, so Windows may show *"Windows protected your PC"*. Click **More info → Run anyway**.
3. In the app, open **Settings**:
   - **eStream → Data source**: choose `Sql` to use the real eStream database (read-only). It starts on `Mock` sample data.
   - **Claude**: paste the Anthropic Console API key, click **Save key**, then **Test connection**.

To update later, run the newer installer. Settings and the saved API key are kept, in `%LOCALAPPDATA%\eStreamAssistant\`. Uninstalling also keeps them.

## What's in it

- Scan a barcode, or type a UPC or item name in the top box. The item card shows price, costs, deposit, stock and GM%.
  - UPCs with missing or extra check digits are handled.
  - Name search is fuzzy, and you pick from numbered choices.
- **Chat with Claude** (`claude-opus-5-5`). You can ask about prices, items, deposit codes, and markup or margin math.
  - Claude can only look things up.
  - When it isn't sure which item you mean, it shows numbered choices as buttons.
  - The chat footer shows a cost estimate for today and this month.
- A scan list, plus status lights for eStream, the database and Claude.
