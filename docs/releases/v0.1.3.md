# eStream Assistant v0.1.3 (test build)

No app changes since v0.1.2. This version adds the GitHub Actions workflows:

- **CI** builds and tests on every push to `main`.
- **Release** builds the installer on Windows with Inno Setup and publishes a release when a `v*.*.*` tag is pushed.

## Install

Download **eStreamAssistant-Setup-0.1.3.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"* because the installer isn't signed yet: click **More info → Run anyway**.
Updating keeps settings and the saved API key. See `todo.md` for what still needs testing.
