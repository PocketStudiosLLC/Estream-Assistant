# eStream Assistant v0.1.7 (test build)

Fixes from test 2 on the store PC (v0.1.6, 2026-11-23). Everything in test 2 passed; these are the problems it found.

## Fixed
- **GM% now matches eStream.** eStream works out GM on the cost of one pack (case cost ÷ packs per case), not
  the cost per unit. For items with more than 1 unit per pack, the pending list, the receipt table and the
  margin report showed the wrong GM (99% instead of 87.9% on the TEST item). Prices worked out from a markup
  or margin now use the pack cost too.
- **A failed stock sheet POST is shown as failed.** The post script says "POSTED BUT CHECK" when eStream refuses,
  but still ends "OK". The app now needs "POSTED OK" before it marks a sheet posted.
- **No stock sheets whose counts add up to 0.** eStream refuses to post them ("net zero total item count"). To set
  items to 0 on hand, use *Change…* on the item card.
- **"N for" prices eStream refuses are caught early.** $98.50 for 3 doesn't split evenly into cents, and eStream
  refuses it. The row is now skipped before the check, and the message gives prices that work ($98.49 or $98.52).
- **Claude no longer mixes up SAVEs.** The notes Claude gets after each SAVE now give the time, what happened
  (saved, stopped at the check, or cancelled) and the rows. Cancels and stops are written to the app log too.

## Changed
- **Price batches only from 4 items.** Test 2 timed it: the item editor takes about 33 s an item, and a price
  batch about 100 s for 2 items. The batch only saves time from about 4 items, so 2 or 3 price changes now go
  through the item editor.
- **A loud warning when the app uses MOCK data on the store PC.** Before test 2, the store PC was set to Mock.
  If the eStream scripts are on the PC but Settings say Mock, the app now says so in red when it starts.

## Install
Download **eStreamAssistant-Setup-0.1.7.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
Then follow `docs/test3.txt` on the store PC.
