# eStream Assistant v0.2.4 (test build)

The Pending tab only asks what it needs to.

## Fixed
- **Only the rows that need you.** A receipt saved for later asked about every row, even ones the chat was happy
  with. Items set up in eStream as 1 pack × 1 unit (normal for things bought one at a time at Superstore or Costco)
  no longer get a question. You're only asked to check a row when its quantity × price doesn't match the line total,
  or a case item's cost looks far off.
- **No count asked when it was read.** The quantity read off the receipt is used. You're only asked for a count when
  it couldn't be read, or eStream has no case size for the item.
- **An item scanned more than once is asked about once.** Rows for the same item (e.g. scanned 3 times at the till)
  share one question: *"Scan the barcode for rows 2, 5 and 7 on the receipt (the same item, 3 times)"*. One scan,
  pick, or "Leave it out" answers all of them.

## Install
Download **eStreamAssistant-Setup-0.2.4.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings, the saved API key, and
receipts saved for later.
