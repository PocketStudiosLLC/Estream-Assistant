# eStream Assistant v0.1.2 (test build)

Includes everything from v0.1.1 (pending changes, dry run, SAVE, History, stock counts), plus receipts and the
smaller items from the spec. Tested with mock data and the mock engine only. See `todo.md` for what still needs
testing on the store PC.

## Install

1. Download **eStreamAssistant-Setup-0.1.2.exe** below and run it. Admin rights aren't needed. It installs to
   `C:\eStreamAssistantApp\` and adds a Start menu shortcut.
2. The installer isn't code-signed yet, so Windows may show *"Windows protected your PC"*. Click **More info → Run anyway**.
3. In **Settings**: set *Data source* to `Sql` for the real eStream database (read-only), paste the API key and
   press *Test connection*. Leave *Dry runs with* on `Mock` until the scripts have been tried with someone watching.

Updating keeps settings and the saved API key.

## New

- **Receipts and invoices:** drag in a photo or PDF, paste it (Ctrl+V), use *Add receipt…*, or drop it in
  `C:\eStreamAutomation\Receipts`. Claude reads the lines into a receipt table; the app matches items, works out unit
  costs, flags anything to check, and works out prices ("30% markup on the chips"). Nothing is changed until you add
  lines to Pending changes and SAVE. *Finish receipt* files it in `Receipts\Done`.
- **Stock counts from a photo** of a count sheet (you confirm before they go in the list).
- **Edit** on a pending row, **Retry** after a failed chat message, and a note suggesting *New chat* after a long chat.
- **History** filters by date and by status.
- **Settings:** usage today and this month, Claude prices, barcode digits, protected price batches, debug log,
  *Open Power Automate Desktop*.
- Engine calls are logged with arguments, exit code and time.
