# eStream Assistant v0.1.6 (test build)

Built from the store PC's Phase C hand-off (the real eStream scripts and screens).

## Simpler saving
- **SAVE is one step.** It checks every change in eStream first (the dry run), then shows the list and asks. If the
  check finds a problem, nothing is saved and the rows say why. *Dry run* is still there as an optional check.
- **Price batches, automatically.** When 2 or more items change only price, "for" or case cost, SAVE puts them in one
  eStream price batch and applies it (no undo; eStream can take a few minutes). Other changes, and prices that don't
  end in 0 or 5, still go through the item editor. Nothing to set up.

## New
- **Receipt → stock sheet**: *Add stock (stock sheet)…* on a receipt (or ask Claude) makes a stock sheet with
  count = on hand + received (a negative on hand counts as 0). Post it from the Stock counts tab as usual.
- **Queue shelf labels in eStream**: *Queue in eStream…* on Reports → Shelf labels to print (or ask Claude).
  Settings → *Label design* (default GROCERY SHELVES). The labels are printed from Labels Print in eStream.
- Store reports (suggested orders, margins, stock value, promotions, sales history), price warnings for mix match,
  specials and pending batches, and a **?** help window.

## Fixed
- Saved changes now show *Applied* (the engine's "Saved" status wasn't recognised).
- SAVE files are no longer written to the engine's `Inbox\`, where a later plain `Invoke-EsCsv.ps1` run could apply
  them again. **Move any old `assistant_*.csv` out of `C:\eStreamAutomation\Inbox`** (see `docs/test2.txt`).
- Short codes such as PLU 4011 no longer also match 401; searches ignore "drink" like the eStream scripts.

## Install
Download **eStreamAssistant-Setup-0.1.6.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
Then follow `docs/test2.txt` on the store PC.
