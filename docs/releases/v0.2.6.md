# eStream Assistant v0.2.6 (test build)

Fewer questions on Costco and other store receipts: the app remembers your picks, finds more items by their code,
and shows what tells look-alike items apart.

## New
- **Your picks are remembered.** When you pick or scan the item for a code on a store's receipt (in the receipt
  table, on the Pending tab, or in the chat), the next receipt from that store matches that code by itself:
  *"matched by your earlier pick (Nov 27)"*. The same code further down the same receipt matches straight away
  too. Picks are kept per store (a Costco number doesn't match a Superstore receipt) and on this PC only; nothing
  changes in eStream. Picking a different item for the code replaces it.
- **More items found by their code** before you're asked to pick from similar names: the shelf code now matches
  with or without leading zeros and spaces ("014094" = "14094"), and supplier item numbers kept in eStream
  (VendorItems) are checked too.
- **Look-alike items can be told apart.** When you have to pick (e.g. two "MOTT'S CLAMATO - ORIGINAL"), each
  choice shows its case size, price, case cost, on hand, sales in the last 4 weeks and when it was last received,
  and the one whose cost is closest to the receipt price is marked.

## Fixed
- **No "1 pack × 1 unit" check on every line.** Items bought one at a time are normal; the check only shows when
  eStream has no cost to compare with.
- A line with no count printed shows **qty 1**, also before its item is picked.
- The Pending tab's receipt card counts what's left the same way as the open receipt ("32 to do").
- Opening a big receipt on the Pending tab says *"Opening… Matching its 53 rows to eStream items"* instead of
  looking like nothing happened.

## Install
Download **eStreamAssistant-Setup-0.2.6.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings, the saved API key, and
receipts saved for later.
