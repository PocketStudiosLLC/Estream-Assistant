# eStream Assistant v0.2.7 (test build)

Receipt PDFs show on the Pending tab, saved receipts can be deleted, and scanned Costco receipts read better.

## New
- **PDF receipts show in the receipt box** on the Pending tab, with zoom and scrolling, instead of opening in a
  separate viewer. Scanned PDFs show their scans; typed PDFs (e.g. a supplier's emailed invoice) are drawn with
  Windows' own PDF reader. "Open the PDF" is only offered if a PDF can't be shown.
- **Delete** a receipt on the Pending tab (a duplicate, a mistake, or one you won't do). It asks first. The
  receipt's file goes to Receipts\Done so the scan isn't lost. Deleting never changes eStream: if a stock sheet was
  made from the receipt and isn't posted yet, it tells you to delete that sheet in eStream (Inventory > Stock
  Sheets) if you don't want it.

## Fixed
- **Black-and-white scanned PDFs** (the store scanner's Costco receipts) are now sent to Claude as clear pictures,
  cut into strips like photos, instead of one very tall page shrunk down. Claude reads them more reliably, and on
  the Pending tab the rows that need you are highlighted on the receipt.
- Rename, Finish and Delete are the same size, in one row.

## Install
Download **eStreamAssistant-Setup-0.2.7.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings, the saved API key,
remembered picks, and receipts saved for later. Needs Windows 10 (version 1809) or later.
