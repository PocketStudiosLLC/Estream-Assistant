# eStream Assistant v0.1.1 (work in progress)

Saves the work on Phases 3, 4 and 6. Tested with the mock engine only; the PowerShell engine still needs
its first runs on the store PC (one item at a time, with someone watching eStream).

- **Phase 3, changes + dry run:** Pending changes list (from Claude's `stage_changes` or the item card's *Change…*),
  app-side safety rules, *Allow large change*, dry run through `Invoke-EsCsv.ps1 -DryRun` with a "don't touch" overlay.
- **Phase 4, SAVE + History:** a confirmation listing every change, apply with the exact CSV that passed the dry run,
  read-back check (Applied / Unverified), interrupted-save detection, and the History tab.
- **Phase 6, stock counts:** scan-and-count, CSV import, over/short preview, *Check*, *Make stock sheet* (confirmed,
  never the same counts twice), and *Post* (post check, then type the sheet number). Settings → *Protected sheets*.
- Fixes: the Inter font now applies everywhere, body text is no longer all semibold, dark check boxes.

Not done yet: Phase 5 (receipts), *Stop after current item* (U8).
