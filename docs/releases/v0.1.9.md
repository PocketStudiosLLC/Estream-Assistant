# eStream Assistant v0.1.9 (test build)

Fixes from test 4 on the store PC (v0.1.8, 2026-11-23). Everything in test 4 passed; these are the problems it found.

## Fixed
- **Claude's lists show properly in the chat.** Every numbered list was turned into choice buttons, so a list of
  facts (what a save did, what a receipt line shows) became buttons, and a second list made the first one disappear.
  Now only a list that asks something ("Which one?", "What would you like to do?") or names items by UPC becomes
  buttons; other lists stay in the text. Claude is also told to number only choices.
- **Sheets deleted in eStream.** A sheet the app made that was later deleted in eStream (Costco sheet 10763) now shows
  "deleted in eStream" and can't be posted. The app checks when it starts and before every post.
- **Settings file.** The new time limits (120 s + 90 s per item) are written to settings.json when the app starts,
  not only when Settings are saved.
- **Item card GM note.** "it uses the case cost ÷ packs only" now only shows for "1 × N" items; other items just say
  what eStream shows.
- "POSTED OK: ... match the counts.." no longer ends with two full stops.

## New
- **12-digit barcodes warning.** eStream's stock sheet import left MINI BELLA MUSHROOMS (771163002506) off sheet 10763;
  it was the only 12-digit barcode on the sheet. The stock sheet window now lists items with a 12-digit barcode and
  says what to do if one goes missing (the script still checks the sheet afterwards).

## Install
Download **eStreamAssistant-Setup-0.1.9.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings and the saved API key.
Then follow `docs/test5.txt` on the store PC.
