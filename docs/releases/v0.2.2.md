# eStream Assistant v0.2.2 (test build)

A new **Pending** tab for receipts you can't finish right away, and Sonnet as the chat model.

## New
- **Save a receipt for later.** When a receipt still needs barcodes or answers, press **Save for later** on the
  receipt card. It moves to the new **Pending** tab (between Assistant and Stock counts) and leaves the chat.
- **Pending tab.** Click a saved receipt and the app goes through what's missing one row at a time, for example
  *"Scan the barcode for row 4 on the receipt: 'Lays Chips 220g'"*. The receipt picture shows beside the stock
  sheet rows, with the rows that need you highlighted. Scan, pick, type a number, or leave a row out, then press
  **Make stock sheet**. None of this uses Claude.
- **Receipts are named by store and date**, for example *"Superstore · Nov 25, 2026"*. Press **Rename** to give a
  receipt your own name. The eStream stock sheet comment says which receipt it came from.
- **Claude remembers saved receipts.** Questions like "what did we pay for Lays at Costco?" are answered from the
  saved receipts without sending the picture again, which saves on Claude costs.

## Changed
- **The chat now uses Claude Sonnet by default** (receipts still work the same). PCs set to Opus are moved to
  Sonnet once; you can change it back in Settings.

## Install
Download **eStreamAssistant-Setup-0.2.2.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"*: click **More info → Run anyway**. Updating keeps settings, the saved API key, and
receipts saved for later.
