# eStream Assistant v0.1.4 (test build)

## New
- **Reports tab** (read-only): negative stock, below minimum, above re-order max and zero stock, worst first with totals;
  eStream's stock sheets (open first) and each sheet's items with system vs counted, over/short and value at cost.
  Export any report to CSV or print it. Double-click a sheet in the list to open it.
- **Claude can answer questions about many items at once**, e.g. "which items have negative stock?" (`stock_report`), and
  check stock sheets, e.g. "check sheet 10750" (`stock_sheets`), with checks before posting: items counted 0, big differences,
  negative system stock, sheets that weren't counted yet. Claude gets the totals and the worst items; the full list is on the
  Reports tab. Neither tool can change or post anything.
- **Two Claude models**: text messages use the chat model (default Sonnet 5.5), messages with a photo or PDF use the receipt
  model (default Opus 5.5, medium effort). Haiku 5.5 prices are built in for cheap testing.

## Check on the store PC
Some stock sheet column names aren't confirmed yet. At startup the app compares them with eStream's tables and writes the
result to the app log: "Stock sheet tables: columns as expected", or "Stock sheet tables are different…" with the real
columns. Until they match, stock sheet reading is off; the stock reports work either way. See `todo.md`.

## Install
Download **eStreamAssistant-Setup-0.1.4.exe** below and run it (no admin rights needed). Windows may show
*"Windows protected your PC"* because the installer isn't signed yet: click **More info → Run anyway**.
Updating keeps settings, the saved API key, the count list and the app's stock sheet records.
